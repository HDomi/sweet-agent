description: 스윗 강도, 슬래시 커맨드, 트리거 참조 카드
---
스윗 참조 카드를 보여준다.

| 명령 | 뭐 하나 |
|---|---|
| `/sweet` | 기본 강도(full)로 켜기 |
| `/sweet lite` | 약한 압축 — 군더더기만 제거 |
| `/sweet ultra` | 최대 압축 |
| `/sweet off` | 끄기 |
| `/sweet-commit` | 짧은 커밋 메시지 |
| `/sweet-review` | 한 줄 리뷰 발견 |
| `/sweet-compress <파일>` | 마크다운 파일 압축 |
| `/sweet-stats` | 누적 토큰 절감 |

자연어도 된다: "스윗 켜", "다정하게 말해", "반말로 해", "스윗 끄기", "그만", "normal mode".

코드, 커밋, 보안 경고에서는 스윗이 자동으로 빠진다.
